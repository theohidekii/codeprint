# Codeprint

> The fingerprint of code.

Codeprint is a toolkit for investigating code:

- **Trace**: paste a snippet and find public repositories that contain it, even when identifiers were renamed.
- **Snapshot**: turn a snippet into a polished, shareable image.
- **Fingerprint**: generate unique art from a GitHub user or repository.
- **Blueprint**: see a repository's architecture drawn as a technical blueprint.
